# Windows Notepad and Notepad++ import

Choose **Import from Windows Notepad…** in a folder menu to preview and copy unsaved tabs to that folder. Settings offers the same flow, defaulting to an existing **Notepad Imports** folder or creating one when notes are imported. Destinations include any existing folder and Unfiled notes. No account, remote service, or paid feature is involved.

The native command reads the current Windows user's `LocalState/TabState` files under the Windows Notepad package in `%LOCALAPPDATA%`. Only UUID-named `.bin` content buffers are candidates; `.0.bin`/`.1.bin` settings sidecars and backup files are excluded. Notepad and original saved files are never written, closed, deleted, or opened by the importer. Classic Notepad and tabs without session recovery data require saving `.txt` files for ordinary file import.

The bounded parser reads structured UTF-16LE buffers and validates big-endian CRC32 checksums. Pending insertion/deletion/replacement chunks replay in UTF-16 units so Unicode and emoji offsets stay correct. Newer formatted tabs share the recovery content buffer; their text/Markdown syntax is copied literally, without reconstructing rich formatting. Unsupported, changing, truncated, corrupt, or oversized files get individual skip explanations; valid tabs remain importable. Saved-file tabs with only pending edits and no recovery base are skipped rather than reading arbitrary saved paths or guessing their contents.

Limits: 16 MiB per recovery file, 2 million UTF-16 units per resulting tab, 32 MiB of recovered UTF-8 text per scan, 1,000 candidate tabs, and 100,000 pending edits per tab. Larger notes can be saved from Notepad and added through ordinary file import. Scanning runs on a blocking worker outside the UI thread. Closing the import dialog ignores any late scan result. Nothing is added until Import is activated.

Import uses one workspace update and existing recovery/autosave storage. It rechecks the destination and compares note text against the latest workspace immediately before adding copies. Existing matching text in the destination (including archived notes) is skipped, as are identical tabs within the chosen batch. Notes in Trash do not prevent reimport. Line-ending differences and final newline differences are ignored for matching; other spacing is preserved. Imported notes bypass Copy last note, preserve existing notes and Reference, and select the first new note. A success toast waits for persistence acknowledgement; failed saves keep the new drafts and expose Retry. The editor's initial and replacement HTML parsing preserve source whitespace. Passive toasts cannot intercept clicks on save/retry controls.

The interface reuses Dialog, AppSelect, folder action menus, theme tokens, native checkboxes, and existing focus/opacity/reduced-motion behavior. Content stays solid; there is no new gesture, spring, blur animation, or UI dependency. Escape/dismissal returns focus to the folder or Settings trigger. The destination picker and checkboxes retain keyboard operation. The browser preview offers the existing saved-file picker with the folder destination preserved.

## Notepad++

Choose **Import from Notepad++…** in a folder menu or Settings. Settings defaults to an existing **Notepad++ Imports** folder, or creates it on import. The destination, selection, duplicate checks and acknowledged-save behavior are shared with Windows Notepad. Both unnamed tabs and modified named files can be copied when they have a periodic snapshot.

Enable **Remember current session for next launch** and **Enable session snapshot and periodic backup** under Notepad++ **Settings → Preferences → Backup**. Wait for the configured interval, then use **Scan again**. The default source is `%APPDATA%\Notepad++\backup`. **Choose backup folder…** accepts either the profile folder or its `backup` subfolder for portable or relocated installations. Cancelling that picker retains the previews and selected tabs; Scan again retains the chosen source for the open dialog. The separate custom backup-on-save directory is not the periodic snapshot source.

The native scanner only reads immediate files named `title@yyyy-mm-dd_hhmmss`. It ignores `.tmp` writes, ordinary saved files, `.bak` files, directories and linked/reparse entries. It never follows `filename` or `backupFilePath` from session XML, changes Notepad++ settings, or writes/removes snapshots. A snapshot may outlive the tab it came from; previews represent available recovery snapshots, not a live list of editor windows. Tabs with no snapshot need ordinary file import.

UTF-8 with or without a BOM and UTF-16LE/BE with BOM are decoded strictly; Unicode, tabs, spacing and line breaks are preserved as plain text. Legacy non-UTF-8 encodings, binary controls, invalid Unicode, locked/changing files and oversized snapshots get individual skip reasons. For unsupported encodings, save the tab as UTF-8 and use Import files. Limits are 16 MiB per snapshot file, 8 MiB of decoded UTF-8 text per tab, 32 MiB per scan and 1,000 candidates. Scanning and the native folder picker run on a blocking worker.

## Format references

The parser follows the fields documented in [ogmini's Notepad State Library](https://github.com/ogmini/Notepad-State-Library) and its [TabState format pattern](https://github.com/ogmini/Notepad-State-Library/blob/main/PatternFiles/Tabstate/Notepad-TabState.hexpat), with checksum byte order verified against local recovery data. [Markdown recovery research](https://ogmini.github.io/2025/06/28/Windows-Notepad-Markdown-Support.html) explains the newer content-buffer behavior. This is an undocumented Windows format; future incompatible versions are reported as skipped tabs instead of guessed text. No third-party parser source was copied.

Notepad++ naming, backup settings and lifecycle follow its [official preferences documentation](https://github.com/notepad-plus-plus/npp-usermanual/blob/master/content/docs/preferences.md#backup). Snapshot encoding and write behavior were checked against [Notepad++ FileManager::backupCurrentBuffer](https://github.com/notepad-plus-plus/notepad-plus-plus/blob/master/PowerEditor/src/ScintillaComponent/Buffer.cpp). No Notepad++ implementation source was copied.
