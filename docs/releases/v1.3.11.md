# Scribly 1.3.11

Scribly is now available here as a free, MIT-licensed Windows notebook. Download **Scribly_1.3.11_x64-setup.exe** from the release assets. Contributors can fork the repository and open pull requests; see [CONTRIBUTING.md](https://github.com/Malon0825/scribly/blob/v1.3.11/CONTRIBUTING.md).

## Latest fix

- Improve the running Windows 11 taskbar icon's resolution by assigning the existing high-resolution ICO frame to the taskbar-facing native icon slot.
- Retain Light/Dark/System icon synchronization, cached native handles, and the stable application identity used by existing notebooks.

This first public GitHub release includes the current notebook and board features: folders/search, rich-text/code/checklists, embedded images, pen/marker tools, read-only Reference, Focus, Excalidraw boards, offline brand logos, Mermaid/Miro exports, document imports, local autosave, and portable backups.

## Install or update

- **Platform:** Windows 10/11 x64. Other operating systems and architectures are not supported by this installer.
- Run the setup EXE; installation is per user and does not require administrator access.
- WebView2 is required. Setup downloads Microsoft's runtime if missing, which may require internet access on first installation.
- PostgreSQL is included. No separate server, account, Docker, or cloud setup is needed.
- Before updating, export a portable backup from Settings, close Scribly, and run this installer. Notebook data is preserved under `%LOCALAPPDATA%\com.still.notes\database`.

## Trust and limitations

The installer is **unsigned** and may trigger an unknown-publisher or Windows SmartScreen warning. Download only from this repository's release assets. Verify the installer with the attached `SHA256SUMS-release.txt`; in PowerShell run:

```powershell
Get-FileHash .\Scribly_1.3.11_x64-setup.exe -Algorithm SHA256
```

There is no cloud sync, shared editing, or automatic updater. Pinned shortcuts and the closed app retain their static packaged icon. Native icon diagnostics inspect Windows handles and Shell properties; they do not establish how Explorer visually renders the taskbar on every display.

Scribly's source is MIT licensed. Third-party dependencies, fonts, and brand artwork retain their original licenses and notices, included with the app. Report reproducible problems through [GitHub Issues](https://github.com/Malon0825/scribly/issues), using sample content rather than personal notebooks.
