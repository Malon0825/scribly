# Scribly 1.4.1

Unpublished changes; release is on hold.

- Fixes online dictionary lookup for words outside the bundled WordNet dictionary. The previous provider returned server timeouts even with a working internet connection.
- Uses [FreeDictionaryAPI.com](https://freedictionaryapi.com/) for online English definitions, pronunciations, examples, synonyms and antonyms. Content comes from [Wiktionary](https://en.wiktionary.org/) under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); individual results link to their source and license. Only the lookup word is sent.
- Words without a definition, including `awd`, show **No entry found**. Service failures no longer tell you to check your internet connection.
- WordNet still works offline. Dictionary replacement, Undo and note saving keep their existing behavior.
- Fixes large vertical gaps when copying headings and lists to plain-text destinations such as Notepad or Discord. Copy/cut retains bullets, original list numbering, checkbox states and nested indentation, alongside intentional blank paragraphs, hard line breaks and code indentation. Copying only part of a word or sentence does not add list markers. Rich HTML stays available for formatted paste.
- Preserves section separation as a single blank line between headings/paragraphs and after lists. Each heading stays attached to its following list, and list items remain on consecutive lines. Explicit blank lines are retained without adding another section gap.
- Replaces Archive with recoverable Trash. Move notes, boards or whole folders into Trash, restore them anytime, or confirm Clear Trash to remove them permanently. Existing archived items move into Trash. Drag notes and folders directly onto its sidebar icon; the lid opens throughout dragging and the destination highlights on hover. Reduced motion uses an instant lid change.

## Install or update

Windows 10/11 x64: export a portable backup, close Scribly, and run `Scribly_1.4.1_x64-setup.exe`. Existing notebooks remain under `%LOCALAPPDATA%\com.still.notes\database`. PostgreSQL is bundled; missing WebView2 may require internet access. Verify the installer with `SHA256SUMS-release.txt`.

Scribly is free and MIT licensed. Bundled data and third-party content retain their own licenses. Updates are installed manually.

## Validation

Seven affected browser cases passed across focused runs: lookup and replacement in Light/Dark/Notebook, Undo and saving, formatting preservation, offline WordNet, superseded requests, retry/cache/missing words, and the new response format with source attribution under the desktop Content Security Policy. Initial development-preview timing failures passed on focused reruns with a 60-second test timeout; the new parsing/attribution test uses an explicit lookup instead of relying on automatic text-selection timing.

Live HTTP checks found the previous provider returning HTTP 522 for both `awd` and `hello`. The replacement returned HTTP 200, an empty entry list for `awd`, definitions for `hello`, and an Access-Control-Allow-Origin header permitting the Windows app origin.

Live browser checks against the production frontend confirmed `awd` displays **No entry found** and an online-only word displays definitions, pronunciation, examples and attribution after HTTP 200 responses. No native WebView2 runtime or install/upgrade flow was exercised.

Three clipboard browser cases passed across focused runs for compact note/Reference copy, partial selections, unchanged rich HTML, cut/Undo and saving after reload. Explicit blank lines, hard breaks and code indentation were preserved. OS clipboard and external-app paste were not exercised. The earlier dictionary-only installer excludes the clipboard change; a combined installer has not been packaged.
