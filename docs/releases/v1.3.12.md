# Scribly 1.3.12

New notebooks now start with **one Introduction folder** and **one Welcome to Scribly note**. The welcome note explains how to create notes, folders and boards, use Search/Reference/Focus, and export backups.

The earlier work-log, data-integration, meetings and personal examples are no longer prepopulated. Create only the folders you want. There is no default Reference note.

**Existing notebooks are preserved.** Updating does not delete, rename or reset your saved folders, notes or drafts. The new starter is used only when there is no saved notebook or recovered draft.

## Download and update

Download **Scribly_1.3.12_x64-setup.exe** from the assets below. Supports Windows 10/11 x64. Installation is per user, PostgreSQL is bundled, and WebView2 is installed from Microsoft if missing (first installation may require internet access).

Export a portable backup from Settings, close Scribly, and run the new installer. Data remains under `%LOCALAPPDATA%\com.still.notes\database`. The installer is unsigned and may trigger a Windows warning. Verify the download using `SHA256SUMS-release.txt`.
