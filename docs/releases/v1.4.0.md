# Scribly 1.4.0

- Select a word to open an English dictionary beside your note, with definitions, synonyms, and antonyms. WordNet 3.1 works offline; unlisted words use the Free Dictionary API online.
- Click a synonym or antonym to replace the matching selected word while preserving formatting and capitalization. Undo restores the previous word.
- English paragraphs and headings offer subtle word suggestions from Datamuse. Type a space for the next word, press Tab to accept, or Escape to dismiss. The toolbar toggle remembers your preference.
- Includes the Notebook theme for notes and boards, with restored icon animations and support for reduced motion.

Suggestions send the previous word, typed prefix, and up to five nearby topic words to Datamuse. They use statistical associations and do not understand full sentences. Network delays or missing results may leave no suggestion. Datamuse will require API keys starting January 1, 2027; key support is not included in this release.

## Install or update

Supports Windows 10/11 x64. Export a portable backup, close Scribly, and run `Scribly_1.4.0_x64-setup.exe`. Your existing notebook remains under `%LOCALAPPDATA%\com.still.notes\database`. PostgreSQL is bundled. WebView2 installation may require internet access if it is missing. The installer is unsigned and may show a Windows publisher warning. Verify the installer with `SHA256SUMS-release.txt`.

Scribly is free and MIT licensed. It has no cloud sync or automatic updater. Bundled dictionary data and other third-party materials retain their own licenses.
