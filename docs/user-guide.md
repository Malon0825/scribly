# Scribly user guide

[Download Scribly](https://github.com/Malon0825/scribly/releases/latest) · [Installation and development](../README.md)

The current source version is 1.4.1. This guide covers large-file sections, backups, history, Trash, retrieval, connected notes, formatted export and quick capture. See the [1.4.0 release notes](releases/v1.4.0.md) for the offline dictionary, word suggestions and Notebook theme, [1.4.1 notes](releases/v1.4.1.md) for the online dictionary fix, and [verification history](../tests/verification.md) for tested versions and limitations.

## Find, replace, and navigation in 1.3.13

- **Ctrl+F** finds literal text in the current note, including formatted and code text. Use Enter/Shift+Enter or the arrows to move between matches; Escape returns to the editing position. **Ctrl+H** adds Replace next/all, Match case and Whole word. Each replacement operation is one Undo step. Items in Trash support read-only Find; Reference stays read-only.
- **Ctrl+K** searches the notebook and shows excerpts. Choosing a result reveals the matching note text, title, original filename, board text or frame name. Board replacement is performed by editing labels on the canvas.
- **Pin item** in note/board options creates a shortcut without moving the item. Open **Notebook navigation** beside Folders, then expand **Pinned** or **Recently opened** to use shortcuts; both sections start collapsed. **Recently opened** holds the last ten live items opened, independently of autosave and modification dates. Trash hides shortcuts; restoring an item restores its pin. Permanent deletion removes shortcuts.

See [retrieval and editing](retrieval-and-editing.md) for keyboard behavior, compatibility and limits. Original-file contents remain immutable and excluded from Find/Replace; annotations around them are searchable. No overall notebook storage cap was reintroduced.

## Protection features in the local 1.3.12 and later installers

- **Settings → Backups and recovery:** choose a Windows backup folder, enable opt-in daily backups while the app is open, or use Backup now. Seven ordinary copies and three copies made before notebook replacement are retained. Browser copies stay in IndexedDB; Download keeps an independent copy.
- **Version history** in note/board options previews dated versions and preserves current content before restoration. Retention is up to 20 versions per item for 30 days within a separate 64 MiB history budget; it does not cap the live notebook.
- **Trash** keeps notes, boards and folders you remove from your working notebook. Restore them anytime, or choose **Clear Trash…** and confirm to permanently delete everything in Trash. Existing archived items move into Trash. Individual **Delete permanently** actions are available inside Trash and require confirmation.
- **Preview restore / Restore from file…** offers Import as new items or acknowledged notebook replacement. Replacement saves a safety copy first. Backups include Trash notes and folders, images, ink, boards, and originals; local version history is excluded.

See [protection and recovery](protection-and-recovery.md) for retention, migration, and verification limits, and [storage and large files](storage-and-large-files.md) for capacity and large-file viewing.

## Architecture boards

Use **Insert → Brand logos** to search the offline [theSVG](https://thesvg.org/) catalog by brand, service, alias or category. Popular puts common architecture tools first; Recent remembers inserted brands, and category chips narrow the results. Results scroll virtually rather than using pages, and the first result is previewed automatically. Variants are grouped under their brand and previews use a neutral backing. Choose a variant and optional dark component background, then **Add to selection** for each component and **Insert components** together. Arrow keys browse and Space/Enter adds or removes the current brand. The picker stays open for further insertions. Each grouped component contains a proportionate PNG logo and editable bound label; connect arrows to its outer shape. Mermaid retains names and topology; drawing PNG/SVG exports retain logos. See [brand-logo integration](brand-logos.md) for asset details.

Create a **New board** (Ctrl+Shift+N) or choose it from a folder's options menu. Board commands share the topbar: **Insert** groups logos, Templates, Import Mermaid and Shape library; **Architecture** opens roles, boundaries and snapping; **Export** groups editable drawing, SVG, PNG, Mermaid and Copy for Miro. New drawing tools default to clean strokes, elbow arrows and object snapping; existing shapes retain their styles. Select multiple shapes to use the canvas alignment controls. Focus gives the canvas more room, and board mode omits the document footer while keeping save status and retry in the topbar. Notebook backups are available in Settings → Backup & restore. Mermaid offers preview, direction and code/file export; structural omissions require acknowledgement. Boards autosave and share folder, Trash, move, duplicate, backup and read-only Reference workflows with notes. See [verification history](../tests/verification.md) and [board usage](boards-implementation.md) for conversion and tool limits.

## Use

- Create notes with **New note**, boards with **New board**, and folders with **New folder**. The arrow beside New note opens **New note options**, including **New from template…**. Rename notes directly, and search titles and text. Search results include snippets around the matching text. Use the sidebar's All items / Notes / Boards filter and Manual / Modified / A–Z order. The list button switches compact and comfortable rows; these preferences are remembered on this device. Manual reordering requires All items and Manual order.
- Drag the sidebar's right edge to resize it. Width is remembered on this device. Arrow keys resize the focused divider; Home/End set limits, Escape cancels a drag, and double-click restores the responsive default.
- In a folder's `…` menu, enable **Copy last note** to start new notes with the most recently created active note's content, including formatting and checked/unchecked tasks. Each new note gets its own title and date and can be edited independently. The option is off by default; empty folders start blank.
- New notes start with the folder name and local date, such as `Notes · Oct 2, 2026`. Further notes in that folder that day add mythology names in A–Z order (Anubis, Baldur, Cupid, …), with a small fun fact below the title. After Zeus, the names repeat as Anubis 2, Baldur 2, and so on. Titles remain editable; existing notes keep their titles.
- Drag folders to reorder the sidebar. Drag notes between notes to reorder, or onto a folder to move them; closed and empty folders accept drops. While dragging a note, an **Unfiled notes** destination appears below the folder tree. Drop there to remove the note from its folder. Changes autosave.
- Write paragraphs, headings, bold, italic, lists, and checklists. Title, divider, toolbar and body share a centered reading column. The title scrolls away while the single-row formatting toolbar stays sticky. Tooltips identify controls and available shortcuts, including Heading 1. Draw/Highlight show their active mode; their separate options buttons open settings.
- **Stroke size** in Highlight and Drawing options offers Small, Medium and Large (Highlight: 8/16/24px; Draw: 1/3/6px). Each tool remembers its size during the editor session. New strokes retain the chosen width through saving, Undo/Redo, Reference and backups; size changes leave existing strokes intact.
- Choose **Draw** beside Highlight to sketch on the note board, including over images. The pen uses thin solid strokes and starts in **Free** mode with **Auto assist** enabled to soften hand wobbles and corners. Turn Auto assist off in Drawing options for deliberate sharp corners; **Guided** makes straight lines at any angle. Assistance applies to new Free strokes; existing strokes retain their appearance. Drawing options offer Default, Accent and Red, and **Clear drawing strokes** removes only pen strokes with Undo support. Wheel switching, Escape, autosave, safe backups and read-only Reference work like Highlight. Each tool remembers its mode/color/size and assistance choice during the editor session.
- Choose **Highlight** in Formatting to draw marker strokes over note content, including images. **Guided** keeps each drag straight at any angle; **Free** follows your hand. Switch using the mode button/options or the wheel while holding a stroke (also while holding the pen button). Idle wheel scrolling stays native. Escape cancels the current stroke and returns to writing. Options offer three marker colors, a keyboard **Highlight selected text** alternative and **Clear marker strokes**. Undo/Redo includes each stroke and clearing. Markers save with the note and portable backups; Reference displays them read-only. Strokes follow their anchor block and image dimensions; changes to text wrapping can change their relationship to individual words.
- Select text and right-click to choose a text color or background highlight. The compact palette offers three choices for each; **More colors** expands to nine. **Default text** and **Default background** reset each independently. Use **Shift+F10**, the keyboard Menu key, or the palette button in Formatting as alternatives. Colors adapt to light/dark appearance, support Undo/Redo, and persist in notes and portable backups. Reference displays them read-only; code and image controls keep their own context menus.
- Add Notion-style image blocks with **Image** in the toolbar, paste a clipboard image, or drag PNG/JPEG/WebP/GIF files into the editor at the insertion point. Folder drops/imports create image notes instead. Desktop note images are stored in the app-owned attachment directory; browser preview and portable JSON backups embed their data. Original files are retained. Each image must be at most 5 MB and 25 million pixels, and additions respect per-item performance budgets; there is no overall notebook storage quota.
- Hover or focus an image to see its resize handles and menu. Drag a side handle to resize while preserving proportions; arrow keys adjust width, Home/End choose minimum/full width, and Escape cancels a drag. Use the dotted handle to move an image between blocks, or Move up/down in its menu. Add a caption, align left/center/right, view at fitted/actual size, download, or remove the image. Removal supports Undo. Reference displays images and captions with viewing/download controls while staying read-only. Images use responsive percentage widths and work offline.
- Use **Code** in the toolbar or **Ctrl+Alt+C** to turn text into a Notion-style code block. Typing three backticks plus a space creates a block; paste a complete fenced snippet to insert one directly. Auto detects common languages, and each block offers an explicit language or Plain text override. Tab / Shift+Tab indent by two spaces; Ctrl+Enter exits the block. Copy preserves code exactly, including whitespace and Unicode. Wrap controls long lines locally. Language choices persist in notes and JSON backups; Reference also highlights code while remaining read-only.
- Code-block formatting uses [Lowlight](https://github.com/wooorm/lowlight) / highlight.js with selected grammars in a separate, on-demand worker. Supported choices: JavaScript/JSX, TypeScript/TSX, Rust, Python, HTML/XML, CSS, JSON, SQL, Shell/Bash, Java, C, C++, C#, Go, YAML, INI/TOML, and Markdown. Automatic detection is a heuristic; short or ambiguous snippets may stay Plain text, and you can select the language. Source code is preserved rather than rewritten by a pretty-printer. Blocks over 50,000 characters remain plain and editable to keep typing responsive. Full library notices accompany the installed app.
- Reference starts closed to leave room for writing. Its empty panel offers up to six recently modified notes and boards to choose from. Hover or focus a sidebar row and choose its book button (**Show as reference**), use the same command in its options, or Alt+click the item. Ctrl+Shift+R toggles the panel; the topbar button shows its open state. Reference stays read-only; open the item or copy a note's content into the current note.
- Add completed checklist entries to a Weekly update; existing entries are skipped.
- **Notebook navigation** beside Folders contains **Unfiled notes**, **Pinned**, and **Recently opened**. **Trash** and **Settings** stay at the bottom of the sidebar. Use an item’s options to **Move to Trash**, or drag a note or folder directly onto Trash; the lid opens over the drop target. Trashing a folder retains its contents and folder settings. Open Trash to restore an item or a folder. Restoring an individual note also brings back its folder; other trashed notes remain in Trash. **Clear Trash…** permanently removes the retained items and folders after confirmation.
- Move notes between folders or duplicate them from the editor note options menu.
- In a folder's `…` menu, choose **Import files…**, or drag files from Explorer onto a folder, one of its notes, the document, or **Unfiled notes** in **Notebook navigation**. Select up to 25 files at once, up to 20 MB each. Each document becomes an independent note named after the file. A drop on the document uses its current folder; closed folders accept files and open after import. Existing notes and source files are retained, and imported content bypasses Copy last note.
- To bring in unsaved Windows Notepad tabs, create **Notepad Imports** (or use any folder), open its `…` menu, and choose **Import from Windows Notepad…**. Review the text previews, keep **Select all** checked or choose individual tabs, then import. Settings offers the same action and can create Notepad Imports for you. Matching text already in the destination folder is skipped, excluding notes in Trash. Originals stay untouched; import copies plain text, Unicode, spacing, and line breaks. For the latest recovery text, close the Notepad window while keeping tabs for next time and use **Scan again**. Empty tabs and fully saved tabs without recovery text are skipped; saved `.txt` files use **Import files…**. Direct recovery import requires the Windows app; the browser preview explains the saved-file alternative. See [Notepad import details](notepad-import.md).
- For **Notepad++**, choose **Import from Notepad++…** in a folder menu or Settings. Preview unsaved backup text and import it into any folder; Settings can create **Notepad++ Imports**. Enable session remembering and periodic snapshots in Notepad++ **Settings → Preferences → Backup**, then wait for its backup interval before scanning. Portable installations can use **Choose backup folder…** to select their profile or backup directory. UTF-8 and UTF-16 snapshots are supported; save other encodings as UTF-8 for ordinary file import. Originals stay untouched and matching text is skipped.
- Import text/Markdown, JSON, CSV, logs, and source files; code and ordinary JSON retain whitespace in code blocks. PDF and Word `.docx` import extracted text, including Word table text. PDFs need selectable text; scanned PDFs need OCR first, protected PDFs need an unlocked copy, and legacy Word `.doc` should be saved as `.docx`. File-specific results explain skipped files while retaining successful imports. Extracted text is limited to 2 million characters and PDFs to 500 pages; large originals use bounded viewing while notes and boards keep per-item performance budgets. There is no overall notebook storage quota.
- Use **Export note** in the note footer for plain text or a full JSON notebook backup. **Back up notebook** exports a full backup directly and turns amber when no export is recorded or the last export is at least seven days old. Settings → Backup & restore also exports/imports backups. History records successful desktop exports; browser preview records a download request, so check Downloads. History describes exports, not the continued existence of the file. **Check for updates** in Settings → About opens the releases page; export a backup before installing an update. Scribly backups keep their original folder structure, add copies of notes, and match folders by name, preserving existing notes. An ordinary `.json` file imports as code instead of being treated as a backup.
- Choose Light, Dark, or System from the topbar Appearance menu or Settings. The topbar icon represents your current preference.
- Settings has Appearance, Startup, Backup & restore and About tabs, with Done always available below the scrolling content. Appearance provides Small, Medium and Large app elements, one 80–150% text-size slider, a note-font picker with a live preview, and Reset defaults. About contains shortcuts, updates and expandable storage/browser details. Preferences autosave with your notebook and survive updates; existing font and size preferences are retained.
- Note fonts apply to note titles, editor content, and Reference; app controls retain their system font. Roboto (including Light), Lato, Caveat, Itim, Gaegu, and Gochi Hand are bundled for offline use. Calibri, Helvetica, and Simple Notes use installed Windows fonts; if unavailable, the picker explains the fallback (Lato or Caveat). Install your licensed copy in Windows and reopen Settings to detect it. Fonts use the system fallback for characters outside the bundled Latin set. Complete bundled-font notices are in `public/font-licenses.txt` and the installed `FONT-LICENSES.txt`.
- Autosave runs after a short pause, on blur, and before the window closes. Save errors are visible and offer retry. An unsaved draft is kept in the webview's local recovery storage when space permits.

Notes live under `%LOCALAPPDATA%\com.still.notes\database`. Updates and uninstalling the app preserve that folder. Export backups periodically from Settings. Copying a live PostgreSQL data folder is not a supported backup method.

New notebooks start with a single Introduction folder and an editable Welcome to Scribly note. Create the folders that suit you. Existing notebooks retain their saved content. The browser preview uses browser storage (IndexedDB for durable bodies/recovery, with legacy local-storage migration); **the installed Windows app uses PostgreSQL**. This version is a personal, single-laptop notebook with no cloud sync or collaboration.

Connected writing: use Link to item/Ctrl+L, then Ctrl+click to open or Alt+click for Reference options. Backlinks list the notes and boards that connect to the active item. Save as template in Note options keeps an independent snapshot; **New note options → New from template…** creates independent notes. Settings manages templates, and folder options choose defaults ahead of Copy last note. See [Connected notes and templates](connected-notes-and-templates.md) for shortcuts, backup remapping and version compatibility (template notebooks require 1.3.14+).

Formatted export: use **Note options → Export formatted…** for the current draft, or **Folder options → Export notes…** for its active text notes. Choose a Markdown ZIP with image files, standalone HTML, or Print / Save as PDF. Review the preview and format differences before exporting. Ink is omitted; original-file blocks include metadata only. Existing plain-text and notebook backup exports remain available. See [Formatted note export](formatted-note-export.md) for formats, limits and verification.

Quick capture: open **Settings → Startup → Quick capture…** to jot plain text into Inbox. **Save** or **Ctrl+Enter** saves without switching your current note; **Open in notebook** saves and then opens it. Escape/Close retain the capture draft. In the Windows app, enable an optional global shortcut in Settings while Scribly is running; Windows startup is a separate preference. See [Quick capture](quick-capture.md) for recovery and shortcut behavior.
